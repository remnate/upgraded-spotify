# Волна — upgraded Spotify

Полноэкранный плеер поверх десктопного Spotify (расширение для [Spicetify](https://spicetify.app)): большая обложка в цвете трека, волна прогресса по реальной громкости, синхронный текст песни с караоке-заливкой по словам, визуализатор вокруг обложки, который качает от баса, и мини-плеер поверх всех окон.

> A full-screen "now playing" player on top of the Spotify desktop client (Spicetify extension): artwork-tinted background, a loudness waveform, word-by-word karaoke lyrics, a bass-reactive visualizer around the cover and an always-on-top mini player. UI is in Russian.

## Что умеет

- **Главный экран:** обложка, название, исполнитель, альбом, «далее в очереди»; фон — размытая обложка, цвет плавно перетекает между треками.
- **Волна прогресса** строится по анализу громкости трека от Spotify; клик — перемотка.
- **Текст песни (T):** синхронизация по строкам из Spotify, если нет — с [LRCLIB](https://lrclib.net). Текущее слово заливается по мере пения, клик по слову перематывает к нему, `[` / `]` сдвигают текст, если отстаёт или спешит.
  - Время отдельных слов почти всегда *оценивается* (источники дают только начало строки): слова раскладываются по длине и подтягиваются к ударам в музыке. Если у трека есть настоящая пословная разметка — берётся она.
- **Визуализатор вокруг обложки:** стили «Лучи» и «Басы», переключение клавишей `V`.
  - С помощником `volna-audio.py` — реальный спектр того, что играет (PipeWire/PulseAudio монитор).
  - Без помощника — синхронная имитация по анализу трека от Spotify.
- **Очередь (Q)**, клик по треку — включить его.
- **Мини-плеер поверх окон (P)** — Document Picture-in-Picture, с текущей строкой текста.
- Повтор, перемешивание, лайк, громкость (колесо / ↑↓ / M), таймер сна, автооткрытие при простое, во весь экран.
- **Кэш:** заранее готовит 3 следующих и 2 предыдущих трека; анализ, текст и цвет хранятся на диске (IndexedDB, ~500 последних треков), уже слушанные треки открываются мгновенно.

## Установка

Нужны десктопный Spotify и установленный [Spicetify](https://spicetify.app/docs/getting-started).

```sh
git clone https://github.com/remnate/upgraded-spotify.git ~/myspotify
ln -s ~/myspotify/volna.js "$(spicetify path userdata)/Extensions/volna.js"
spicetify config extensions volna.js
spicetify apply
```

Открыть: кнопка с волной в верхней панели Spotify или **Ctrl+Shift+V**.

### Реальный звук для визуализатора (Linux, по желанию)

Помощник читает монитор устройства вывода по умолчанию и отдаёт «Волне» только 64 числа спектра + уровень баса (не звук). Слушает только `127.0.0.1:47823`, отвечает только клиенту Spotify и захватывает звук только пока «Волна» открыта.

Нужны `python3`, `numpy` и `parec` (есть в `pipewire-pulse` / `pulseaudio-utils`).

```sh
# сервис ожидает репозиторий в ~/myspotify — поправь ExecStart, если положил в другое место
systemctl --user enable --now ~/myspotify/volna-audio.service
```

Выключить: `systemctl --user disable --now volna-audio.service`.

### После обновления Spotify

Обновление клиента сбрасывает моды Spicetify:

```sh
spicetify backup apply        # или: spicetify restore backup apply
```

## Горячие клавиши

| Клавиша | Действие |
|---|---|
| Ctrl+Shift+V | открыть / закрыть |
| Пробел | пауза / играть |
| ← / → | перемотка ±5 с |
| Ctrl+← / Ctrl+→ | предыдущий / следующий трек |
| ↑ / ↓, колесо | громкость |
| M | без звука |
| T | текст песни |
| ] / [ | текст раньше / позже на 0,1 с |
| V | стиль визуализатора |
| Q | очередь |
| P | мини-плеер поверх окон |
| F | во весь экран |
| L / S / R | лайк / перемешать / повтор |
| , | настройки |
| H | шпаргалка |
| Esc | закрыть |

## Приватность

- Тексты песен: сначала Spotify; если там нет и включено «Искать текст на LRCLIB» — на `lrclib.net` уходят название трека, исполнитель, альбом и длительность. Отключается в настройках.
- Помощник `volna-audio.py` никуда не отправляет звук: только спектр, только на localhost.
- Кэш хранится локально в профиле Spotify.
